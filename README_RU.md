# QazTriber — Умный транскрибатор (v5)

QazTriber — это настольное приложение для macOS, предназначенное для высокоточного преобразования речи в текст. Оптимизировано для работы с **казахским** и **русским** языками.

## Основные особенности (v5)
- **Гибридный движок (Hybrid Engine)**: Поддержка нативных моделей OpenAI Whisper (`.pt`) и моделей формата Hugging Face Transformers (`safetensors`).
- **Индикация статуса моделей**: В меню выбора качества теперь отображается «(загружено)» для моделей, которые уже есть на диске.
- **Запись с микрофона**: Встроенная функция записи аудио для быстрого теста или создания голосовых заметок.
- **GPU Ускорение**: Полноценное использование Apple Silicon (M1/M2/M3) через `MPS` для мгновенной обработки.
- **Интеграция с Hugging Face**: Возможность загрузки любой модели по Repo ID напрямую из интерфейса.
- **Pro-UI**: Современный темный интерфейс на базе `customtkinter`.
- **macOS Native Experience**: Исправленные горячие клавиши (Cmd+C/V/A/X) и Thread-safe прогресс-бар.

---

## Системные требования
- **ОС**: macOS 14.0+
- **Архитектура**: Рекомендуется Apple Silicon (M1+)
- **Зависимости**: Python 3.11, FFmpeg (установка: `brew install ffmpeg`)

## Установка и запуск

### 1. Подготовка окружения
```bash
# Создание виртуального окружения
python3.11 -m venv venv
source venv/bin/activate

# Установка зависимостей
pip install openai-whisper transformers accelerate safetensors librosa numpy customtkinter torch torchaudio
```

### 2. Запуск приложения
```bash
python main.py
```

## Инструкция по использованию

### Режимы загрузки модели:
1. **Авто-скачивание (Whisper)**: Выберите размер модели (Tiny, Base, Small, Medium, Large, Turbo). Приложение само скачает нужные веса.
2. **Свой вариант (Hugging Face)**: Введите ID репозитория (например, `abilmansplus/whisper-turbo-kaz-rus-v1`).
3. **Локальный файл**: Выберите существующий файл `.pt` или `.bin` на вашем диске.

### Процесс:
1. Выберите способ загрузки модели. Уже скачанные модели помечены как **(загружено)**.
2. Либо **выберите аудиофайл** (MP3, WAV, M4A), либо нажмите **«Запись с микрофона»**, чтобы записать тест.
3. Нажмите **«Начать транскрибацию»**.
4. Сохраните результат через кнопку **«Сохранить результат (txt)»**.

## Сборка .app (PyInstaller)
Для создания исполняемого файла используйте готовый скрипт:
```bash
chmod +x build_mac.sh
./build_mac.sh
```
Результат появится в папке `dist/QazTriber.app`.
