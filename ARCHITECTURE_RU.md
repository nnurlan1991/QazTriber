# Архитектура QazTriber (v5)

Этот документ описывает техническое устройство и ключевые решения, принятые в версии v5.

## 1. Гибридный Backend (engine/whisper_engine.py)
Центральный компонент системы — класс `WhisperEngine`, который автоматически определяет тип загружаемой модели:

- **Режим Transformers**: Если в репозитории/папке обнаружен `config.json`, используется `transformers.pipeline`.
- **Режим Native Whisper**: Если передается файл `.pt` или Repo ID без конфига, используется стандартная библиотека `openai-whisper`.
- **Проверка наличия (Status Check)**: Метод `is_model_downloaded` проверяет наличие `.pt` файлов или папок репозиториев в `MODELS_DIR`.

### Ускорение (Device Selection)
Приложение автоматически проверяет доступность `mps` (Metal Performance Shaders) для ускорения на чипах Apple M-серии. В случае отсутствия — откатывается на `cpu`.

## 2. Пользовательский интерфейс (main.py)
UI построен на библиотеке `customtkinter` с применением паттернов для обеспечения отзывчивости macOS:

- **Monkey-patching PyTorch**: Для загрузки старых моделей используется патч `torch.load`, отключающий `weights_only=True` (введено в PyTorch 2.6).
- **Сырой перехват Hotkeys**: Вместо стандартных биндингов Tkinter используется перехват событий `KeyPress` с проверкой битовых масок.
- **Запись аудио (sounddevice)**: Реализована через неблокирующий `sd.InputStream` с накоплением данных в `numpy.array` и последующим сохранением в `.wav` через `soundfile`.

## 3. Многопоточность и UI-Loop
Все тяжелые операции (загрузка весов, инференс) вынесены в отдельный `threading.Thread`. Обновление UI (прогресс-бар, текстовое поле) происходит через метод `.after(0, ...)`, что предотвращает зависание главного окна.

## 4. Сборка (build_mac.sh)
Скрипт сборки учитывает специфику зависимостей `torch` и `transformers`:
- Копирование метаданных (`copy-metadata`) для корректной работы плагинов.
- Включение скрытых импортов (`hidden-import`), которые не подхватываются анализатором автоматически.
- Интеграция статических ресурсов библиотек.
